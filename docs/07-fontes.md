## Regra de reverificação

Preços, franquias, limites de API e termos mudam. Antes de iniciar cada fase, e sempre que um número for usado para
decidir algo, reverifique na documentação oficial e anote a data. Itens mais voláteis:

1. Limites e termos do Claude Pro e da GitHub Action do Claude Code.
2. Franquia do Workers AI e preço por modelo; se o FLUX.2 klein exige Workers Paid.
3. Franquia do Chirp 3 HD e status Preview do SSML.
4. Plano gratuito e limites da API do Buffer (API em beta), campos `isAiGenerated`.
5. Franquia do GitHub Actions.
6. Políticas de IA e de conteúdo inautêntico de YouTube, Instagram e TikTok.
